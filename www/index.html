    How to build with AI and still own it

    1. Write the spec before the prompt.Five lines: what it does, inputs, outputs, one edge case, how you'll test it.
    2. Ask for hints, not files."What's wrong with line 14?" beats "write the solver".
    3. Small diffs only.One change at a time. Read every changed line before it goes in.
    4. Type it, don't paste it.Retype AI code yourself for anything core.
    5. The explain-back test.After any AI help, close the chat and explain the code out loud.
    6. Run it before you trust it.Every function gets a test before you build on it.
    7. Feature freeze 48 hours before a deadline.After that, only fixes and rehearsing.
    8. Declare it honestly.Keep a log of what AI did and what you did.
