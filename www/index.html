    How to build with AI and still own it

    1. Write the spec before the prompt.Five lines: what it does, inputs, outputs, one edge case, how you'll test it.
    2. Ask for hints, not files."What's wrong with line 14?" beats "write the solver". Ask for full code only for parts you've already built once by hand.
    3. Small diffs only.One function or one change at a time. Read every changed line before it goes in.
    4. Type it, don't paste it.For core code (the engine, the maths), retype AI code yourself.
    5. The explain-back test.After any AI help, close the chat and explain the code out loud.
    6. Run it before you trust it.Every function gets at least one test before you build on top of it.
    7. Feature freeze 48 hours before a deadline.After that, only fixes and practising your explanation.
    8. Declare it honestly.Keep a short log of what AI did and what you did.
