# DailyDally

Syed's Duolingo-style path to Python, JavaScript, HTML and CSS: 48 lessons that unlock in order, streaks and XP, an exam pause, a stylus journal with palm rejection, and an AI planner.

## Get the app
Open **Releases** (right side of this page), download the latest `DailyDally.apk`, and open it on your Android tablet. Allow "install unknown apps" once when asked.

Every push to `main` builds a new APK automatically (see `.github/workflows/build-apk.yml`).

## What's inside
- `www/`: the app itself (one HTML file, plus manifest, service worker and icons)
- `assets/icon.png`: the Pix app icon
- `capacitor.config.json`: wraps the web app as an Android app with Capacitor
